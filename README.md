# Resgate VPU — MVP

Aplicação estática em HTML + Tailwind CDN + JavaScript puro.

## Como usar
1. Abra `index.html` no navegador.
2. Informe a data em que os leads foram marcados como "Perdemos".
3. Importe um CSV com:
   `id,nome,canal_de_venda,campanha,contato,endereco`
4. A aplicação calcula D+3, D+7, D+30, D+90 e D+360.
5. Nome e telefone/contato podem ser copiados clicando diretamente no campo.

Não usa banco de dados, localStorage ou backend.
